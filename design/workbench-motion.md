# 工作台色彩与动效

这份规范适用于 `public/workbench/` 独立界面方案，不涉及实际资料库或桌面业务命令。

## 层级归属

- 窗口栏只包含应用菜单、全局搜索与窗口控制。文档标签留在右侧工作区。
- 左侧资料导航与右侧工作区并列，两者的标题行、标签行同高对齐；分界连续，主工作面不再使用外围大卡片或圆角拼接。
- 标签行标识当前文档，内容页头说明当前范围，工具紧邻作用对象。页头与列表靠留白组织，不重复叠加横向底色条。
- 导航位置使用轻量中性底色；文档使用下划线；筛选使用紧凑分段控件；多选使用复选框和行底色。状态色继续表达处理进度，不承担导航层级。
- 行内快捷操作预留空间，悬停不改变列宽；复选框在悬停、焦点、多选时显现，键盘仍可访问。数字列右对齐。
- 列表选中背景、表头和批量操作栏使用同一宽度；复选框内缩，与选中边界分离，不再用贯穿多行的竖线重复表达选中。

## 工作区标签

- `tabs.js` 统一管理标签身份、激活、关闭、查看会话和溢出列表。启动时只有固定的资料库标签。
- 资料库承载全部课件、课程范围、最近打开和回收站；切换这些范围不创建重复标签。筛选、选择、详情及滚动位置在访问其他标签时保留。
- 课件以文件 ID 为唯一身份；重复打开激活已有标签，不重置查看会话。每份课件独立保留页码、页面多选、显示范围、滚动位置。
- 获取课件、任务、设置各为一个可关闭标签。页面滚动位置保留；后台扫描和任务不依赖标签存在，关闭任务标签不会取消任务。
- 整理结果和撤销历史归属课件模型，不归属标签。关闭后重新打开保留结果和上次页码，重新建立页面选择及显示范围。刷新仍恢复示例初始状态。
- 关闭当前标签激活右邻，末尾则激活左邻；关闭其他标签不切换当前页面。移入回收站时移除对应课件标签；重命名自动更新标签标题。
- 标签支持关闭按钮、鼠标中键关闭、方向键和 Home/End、Delete、Ctrl+Tab / Ctrl+Shift+Tab 切换、Ctrl+W 关闭。固定资料库不会关闭。大图和模态对话框优先处理自身按键。
- 标签数量增多时横向滚动，通过右侧列表可直接访问所有标签，活动项自动滚入可见范围。普通标签与关闭按钮为同级控件，不嵌套按钮。

## 色彩职责

- 白色用于主要内容，极浅冷色用于窗口外围和辅助区域。
- 蓝色用于主要操作、键盘焦点、选中反馈；完成、待处理、异常分别使用绿色、琥珀色、橙色。
- 课程目录和文件小图标使用课程色，名称和正文保持深色。课件内容拥有自己的配色，不受界面配色影响。
- 所有状态同时保留文字与图标，不依赖颜色传递含义。

## 动效顺序与尺度

| 层级 | 场景 | 时长 |
| --- | --- | --- |
| 控件 | 悬停、按下、焦点、勾选 | 约 140ms |
| 内容 | 页面切换、筛选、侧栏预览更新 | 120–160ms |
| 面板 | 详情进入、课程目录展开收起 | 约 210ms |
| 反馈 | 选中强调、完成状态变化 | 约 240ms |
| 弹窗 | 对话框、大图、遮罩出现与退出 | 约 180ms |

交互原则：不为每一行依次播放进场动画；普通选中不重新播放整页动效；开关保留原控件；大图翻页保留翻页按钮和焦点；进度只更新数值和进度条；裁剪拖动和坐标不做插值动画。

课件观看继续采用缩略图网格、右侧预览、双击放大。裁剪仅在大图中进行，操作前结束窗口进场位移，确保坐标稳定。

遵循系统的“减少动态效果”设置：CSS 关闭过渡，JavaScript 不启动额外动画。
