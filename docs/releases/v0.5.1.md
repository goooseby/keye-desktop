# 华工课栈 v0.5.1

修复 v0.5.0 中点击窗口关闭按钮无效的问题。v0.5.0 已撤回，请使用此版本。

- 补齐原生窗口销毁权限，修正关闭前保存检查，避免递归触发关闭请求。正在保存时仍会阻止退出，检查通过后正常关闭窗口并退出进程。
- 桌面端统一更名为“华工课栈”，保留旧资料库、安装识别、快捷方式迁移和签名更新链路。
- 提供全新白色工作台、多标签课件整理、课程分组获取、课程管理与删除撤销。
- 缩略图、侧栏及大图同步展示裁剪结果，改善快速翻页闪烁。
- 普通公告与版本更新共用窗口，支持已读、稍后提醒和历史重读。

保留现有课件、裁剪、整理记录和导出文件，无需重新导入。已安装 v0.5.0 的用户可在“公告与更新”中升级，也可下载安装包覆盖安装。
