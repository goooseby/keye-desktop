# 华工课栈 v0.5.0（已撤回）

此版本因窗口关闭权限遗漏已从 GitHub 撤回，请使用 [v0.5.1](v0.5.1.md) 或后续版本。下文仅保留功能变更记录。

桌面端由“课页”更名为“华工课栈”，与 Android 端统一名称。原有资料库、安装位置和签名更新链路继续沿用，无需卸载旧版或重新导入课件。

本次更新重新设计了桌面工作台，以白色内容区、紧凑导航和更清晰的状态提示组织课件获取、整理与导出。

- **多标签工作空间**：同时打开多份课件，在资料库、获取、任务和设置之间切换；各课件独立保留阅读位置、页面筛选、选择和滚动位置。
- **统一公告与更新**：标题栏铃铛集中展示使用公告和版本消息；启动时适时提醒，支持已阅读、24 小时后提醒与历史重读。公告由独立 HTTPS 服务提供，更新包继续通过原有签名更新器校验和安装。
- **课程管理**：左侧课程悬停显示管理入口，可修改课程名称和学期。删除前可选择将课件移至未归类或回收站，确认后有 8 秒撤销时间；关闭应用后待删除计划仍会保留，原始文件和已导出的 PDF 不会因此删除。
- **按课程获取**：扫描结果按课程分组展开，清楚区分可获取、已获取和获取中的课次；课程勾选只包含可获取课次。
- **裁剪预览同步**：缩略图、右侧预览和双击大图均显示已保存的裁剪结果，裁剪编辑时仍可查看完整原图。
- **翻页与交互优化**：复用已解码图片与画布，保留上一帧直到新页面就绪，减少快速翻页闪烁；补充悬停操作、控件反馈与过渡动效。
- **紧凑设置与更清楚的状态**：收拢设置面板、折叠高级参数，增强文字、边界、按钮及整理状态的辨识度；修正获取列表在底部操作栏下方露出的问题。

更新保留现有本地资料库、原始课件、裁剪及整理记录，无需重新导入。可从应用内检查更新，或下载本页 Windows 安装包覆盖升级。
