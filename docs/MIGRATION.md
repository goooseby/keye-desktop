# 本地资料与数据保护

## 资料位置

开发脚本把测试资料放在项目 `.build/dev-data/`。正式安装版使用当前 Windows 用户的 Local AppData 中、以应用标识 `io.github.goooseby.keye.desktop` 命名的目录。课程、课次、页面筛选、任务和设置存于 SQLite；原始文件与预览文件保存在资料库目录。导出的 PDF 存在使用者选择的位置。

重新编译、安装升级或更换程序安装目录，不应修改资料库。清理开发缓存时保留 `.build/dev-data/`。卸载默认保留应用数据；用户在卸载向导中主动选择删除时，只处理应用默认数据目录。自选资料库位置和已导出的 PDF 不由卸载器删除。

## 导入原则

本地文件导入由用户主动选择来源，程序复制或读取后建立课件记录，不修改来源。若将来支持从其他资料库导入，应先预检查数据库格式、显示导入摘要、备份目标，再复制与校验。未知版本的数据库不能直接打开或覆盖。

## 决策记录

- 应用名为“课页”，技术仓库名为 `keye-desktop`，应用标识保持稳定，以便重装后重新使用保留的数据。
- 首期面向 Windows，采用 Tauri 2、Rust、TypeScript 与系统 WebView2。
- 安装目录只存放程序和只读资源；数据库和下载资料保存在用户数据目录。
