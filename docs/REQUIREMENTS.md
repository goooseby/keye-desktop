# 产品需求与验收范围

## 目标

课页帮助使用者获取、整理和导出课程资料：在学校网页中登录，按日期范围扫描课表，按课程和课次获取课件；也可导入本地图片或 PDF。在本地逐页预览、排除无效页，再快速导出或整理后导出 PDF。界面应在大量页面和后台任务运行时保持响应。

## 核心行为

1. 课程是扫描结果的一级单位；一门课程下有多次课，每次课对应一份课件。文件按课程、课次组织。
2. 登录在独立网页窗口完成，后台自动判断登录是否成功；日期范围变化自动扫描，按钮仍允许强制重新扫描。
3. 整理不是导出的前置条件。可直接快速导出，也可逐页筛选。原始页保留，排除状态可恢复。
4. 缩略图、放大预览、键盘上一页／下一页、`E` 排除或恢复、`Shift` 连选、批量操作与撤销应可用。
5. 首次导出时才询问保存目录；取消选择不会产生导出任务。之后可在设置中改变。
6. 下载、预览、合成 PDF 在后台运行，界面不能因耗时工作卡住。失败任务应可诊断与重试。
7. 用户资料与程序安装文件分开。升级程序不能清除课程、原图、筛选状态或导出设置。

## 当前范围

Windows 10/11 为首要平台。当前开发版提供资料库、导入、学校平台连接、扫描、下载、逐页整理和导出。学校平台流程需要账号持有人在真实网络中验收。安装器、卸载入口和应用内更新完成前不发布可安装版本。

## 待优化：外部导入课件的归类入口

外部导入的课件目前默认放入“未归类”。程序已有“新建课程”，也能在课程详情页勾选课件后使用“归入课程”，但这个操作离导入流程较远，首次使用者容易认为导入课件只能永久留在“未归类”。后续应设计从导入完成提示、未归类列表或课件详情直接归类的清晰入口，并考虑批量归类和新建课程的衔接。本轮仅记录问题，不改变导入或归类行为。

## 验收重点

记录安装包大小、首次启动耗时、空闲内存、长课件连续翻页与批量导出的响应。数值以实测为准。测试使用项目内生成或获授权的样例；涉及学校账号和真实课程的验证由使用者在应用中完成。
